# Free activation

[简体中文](ACTIVATION.md) · English

1. Open **FlowFTP → Settings → General**. Under **Free Activation**, click **Copy Machine Code**.
2. Send the app version and the code starting with `FLOWM-` to the developer, Code It Real, in a private message.
3. Paste the entire activation code starting with `FLOWM1.`, and click **Activate**. Transfers are available when the app shows **Activated Permanently**.

Activation is free and permanent. Verification takes place offline on your Mac. Keep your code for updates or reinstalls on the same Mac. Ask for a new code after changing Macs or replacing the logic board. Keep both codes out of public Issues and comments.
