# FlowFTP 0.4.0 验证记录

- 安装包通过 SHA-256 核对，包内应用通过签名验证。包内 libcurl 8.23.0 报告 FTP、FTPS、SFTP 支持。
- 5 组核心检查通过。离线激活检查覆盖有效签名、设备绑定、产品绑定及篡改拒绝。正式安装包中的应用通过离线激活，重读状态为永久激活。
- 在 Mac 的隔离演示应用中验证保存连接、重启保留连接、恢复对应协议和站点。演示录屏使用虚构数据，显示批量文件、同名处理与逐项进度。
- 四种连接模式分别在同源码的隔离 Mac 应用上联网实测，验证自动读目录、128 MiB 文件与四个小文件的进度、覆盖和 SHA-256。HTTP CONNECT 和 SOCKS5h 分别完成四种模式的小文件往返。详细结果见 Release 附件 `GUI-TRANSPORT-RESULTS.json`。
