# FlowFTP

简体中文 · [English](README.en.md)

FlowFTP 是面向 Mac 的文件传输工具。使用双栏窗口浏览本地和远程文件，连接 FTP、FTPS 或 SFTP。读取目录后，可选择文件上传、下载或进入子目录。每次连接可独立选择直连或自定义代理。

适用 Apple Silicon 和 macOS 27.0 及以上。通过连接清单保存常用站点，再打开时直接选择。连接成功后右栏自动列出远程目录。选择多个文件上传或下载时，传输清单显示每项进度和速度。在 FlowFTP 的「设置」中切换中英界面和进行免费离线激活。
